vitest-dev/vitest

Next generation testing framework

Vitest is a Vite-native unit test framework with a Jest-compatible API. It reuses your existing Vite configuration and transform pipeline, so tests run through the same plugins and resolver rules as your application code rather than a separate compilation path.

Installation is a single dev dependency. Run npm install -D vitest and add a test script to package.json. Watch mode is enabled by default during local development and uses the Vite module graph to rerun only the tests affected by a change.

Features

The framework supports TypeScript and JSX out of the box, provides an interactive UI for inspecting test state, and includes built-in coverage reporting through v8 or istanbul. Snapshot testing follows the same format as Jest so existing snapshots can be reused during a migration.
