GET /v2/forecast

Returns a 7-day forecast for a given latitude and longitude. Requires an API key passed via the Authorization header.

Request

GET /v2/forecast?lat=40.71&lon=-74.00&units=metric
Authorization: Bearer YOUR_API_KEY

Parameters

Name Type Required Description
lat float yes Latitude in decimal degrees
lon float yes Longitude in decimal degrees
units string no metric or imperial, defaults to metric

Response

{
  "location": "New York, US",
  "daily": [
    {"date": "2026-07-15", "high": 29, "low": 21, "condition": "partly_cloudy"}
  ]
}

Rate limits

Free tier requests are limited to 60 calls per minute. Exceeding this returns a 429 status with a Retry-After header.
